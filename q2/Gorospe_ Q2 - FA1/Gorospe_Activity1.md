1. What is/are the parent class/es of the Programmer class in the video?
Answer: Person and Employee are both parent classes. Person is a parent class to Employee while Employee is a parent class to Manager, Programmer, and Cleaner.
2. If you were to add a new role called Intern, where would you place it in the inheritance
hierarchy? Why?
Answer: Intern would be placed as a child class to Employee since the intern job falls under the description as an employee.
